О формате IUTF

IUTF - это формат данных, основанный на ветка, подобных Git. В данном руководстве я расскажу о всём, что нужно знать: API, AST, и основы парсера IUTF, а также немного про расширения для него.

Требования: Для работы с API IUTF вам нужно обладать минимальным пониманием языка Си и памяти. Примеры будут на C, Vala и Php.

Установка

У нас есть 2 варианта: Сборка или пакеты (pacman, apt, dnf). Я рекомендую использовать 1 вариант - сборку, так вы получите самый свежий бинарный файл и библиотеки к нему. Для быстроты есть возможность установки напрямую через пакетный менеджер. 


            git clone https://github.com/gnom2949/IUTF.git
            cd ~/IUTF
            meson setup build --prefix=/usr
            sudo meson install -C build
        

               # Для Debian-based Систем
               sudo apt install iutf.deb
               # Для Arch-based
               yay -S iutf
               # Для RHEL-based
               dnf install iutf-devel

Установка завершена!

API

Для начала я ознакомлю вас с хедерами, для удобства есть один хедер "iutf/iutf.h" этот хедер включает в себя все зависимости iutf, для использования подключите его: '#include iutf/iutf.h'.

Рассмотрим таблицу где приведены функции из API.

Имя заголовка Функция Что делает Параметры
iutf-api.h iutf_new_branch Данная функция создает корневую ветку. IutfNode* iutf_new_branch ().
iutf-api.h iutf_add_branch Данная функция создает новую обычную ветку. void iutf_add_branch (IutfNode *branch, const char *key, IutfNode *value)
iutf-api.h to_branch Данная функция добавляет ключ-значение в указанную ветку. void to_branch (IutfNode *branch, const char *key, IutfNode *value).
iutf-api.h iutf_new_str Данная функция создает строку с указанным значением. IutfNode* iutf_new_str (const char* value).
iutf-api.h iutf_new_int Данная функция создает целое число с указанным значением. IutfNode* iutf_new_int (long long value).
iutf-api.h iutf_new_float Данная функция создает число с плавающей точкой с указанным значением. IutfNode* iutf_new_float (double value).
iutf-api.h iutf_new_long Данная функция создает длинное число с указанным значением. IutfNode* iutf_new_long (long long value).
iutf-api.h iutf_new_char Данная функция создает символ с указанным значением. IutfNode* iutf_new_char (char value).
iutf-api.h iutf_new_bool Данная функция создает булеву с указанным значением. IutfNode* iutf_new_bool (int value).
iutf-api.h iutf_new_null Данная функция создает атрибут null. IutfNode* iutf_new_null ().
iutf-api.h iutf_new_array Данная функция создает новый массив но без значения. IutfNode* iutf_new_array ().
iutf-api.h add_to_array Данная функция добавляет значение в указанный массив. void add_to_array (IutfNode *array, IutfNode *item).
iutf-api.h iutf_new_BigString Данная функция создает строку 'BigString' с указанным значением. IutfNode* iutf_new_BigString (const char* value).
iutf-api.h iutf_new_PipeStr Данная функция создает строку 'PipeString' с указанным значением. IutfNode* iutf_new_PipeStr (const char* value).
iutf-api.h debug_print_string Данная функция нужна для дебага, она выводит строку из iutf файла. char* debug_print_string (IutfNode* node).
iutf-api.h iutfToJSON Данная функция превращает iutf в json-подобный формат и выводит его в буффер stdout. char* iutfToJSON (IutfNode* node).
iutf-api.h debug_print_recursive Данная функция нужна для дебага, она обходит дерево ast и в частности помогает функции debug_print_string. void debug_print_recursive (IutfNode* node, char** buf, size_t* size, int indent).
iutf-api.h bufInit Данная функция инициализирует буффер-структуру находящуюся в iutf-api.h. void bufInit (IutfApiBuf* buf).
iutf-api.h bufPrint Данная функция печатает в буффер (динамический массив). void bufPrint (IutfApiBuf* buf, const char* fmt, ...).
iutf-api.h ApiGetLastErrLn Данная функция получает последнюю линию ошибки. int ApiGetLastErrLn ().

iutf-api.h ApiGetLastErrMessage Данная функция получает последнее сообщение ошибки. const char* ApiGetLastErrMessage ().
iutf-ast.h iutf_node_new Данная функция создает новую ноду указанного типа. IutfNode* iutf_node_new (IutfNodeType type).
iutf-ast.h iutf_node_free Данная функция освобождает память занятую нодой и его дочерними элементами. void iutf_node_free (IutfNode* node).
iutf-ast.h iutf_branch_list_new Данная функция создает новый пустой список который нужен для хранения имён веток. IutfBrList* iutf_branch_list_new ().
iutf-ast.h iutf_branch_list_free Данная функция освобождает память занятую списком веток и сохранёнными именами. void iutf_branch_list_free (IutfBrList* list).
iutf-ast.h iutf_branch_list_add Данная функция добавляет имя ветки в список. void iutf_branch_list_add (IutfBrList* list, const char* name).
iutf-ast.h iutf_collect_branches Данная функция обходит дерево нод и собирает все имена веток в список. void iutf_collect_branches (IutfNode* node, IutfBrList* list).
iutf-ast.h iutf_has_branch Данная функция проверяет, есть ли ветка с указанным именем в списке, возвращает 1 если есть и 0 если нет. int iutf_has_branch (IutfBrList *list, const char *name).
iutf-ast.h iutf_branch_get_All Данная функция создает список, собирает все ветки из дерева и возвращает список. IutfBrList* iutf_branch_get_All (IutfNode* node).
